# Data

Source: UCI Online Retail Dataset (https://archive.ics.uci.edu/dataset/352/online+retail)

UK-based online retailer transactions, Dec 2010–Dec 2011.
Columns: InvoiceNo, StockCode, Description, Quantity, InvoiceDate, UnitPrice, CustomerID, Country.

The notebooks read the data from `data/Online Retail.csv`. If the CSV isn't included (on GitHub it exceeds the upload size limit), download the dataset from the link above. UCI provides it as an Excel file, so save it as CSV under that name in this folder.
